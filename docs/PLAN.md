### Demo robot (deterministic, no simulator)
| node | publishes | subscribes |
|---|---|---|
| velocity_commander | /cmd_vel (10 Hz) | |
| base_controller | /wheel_states (20 Hz) | /cmd_vel (param `cmd_vel_topic`) |
| wheel_odometry | /odom (20 Hz), TF odom→base_link | /wheel_states |
| lidar_driver | /scan (10 Hz, frame `laser`) | |
| tf_broadcaster | TF base_link→laser (20 Hz) | |
| obstacle_monitor | /obstacle_distance (5 Hz) | /scan, /odom, TF |

All nodes publish `/diagnostics`; crashes log FATAL to `/rosout`.

### Faults (supervisor, never visible to the agent)
| id | mechanism | observable symptoms |
|---|---|---|
| controller_crash | base_controller logs FATAL, exits 1 | /cmd_vel 0 subs, /wheel_states gone, odom frozen |
| lidar_failure | lidar_driver stalls (alive, no data) | /scan 0 Hz, lidar diagnostics ERROR |
| tf_failure | tf_broadcaster hangs (alive, silent) | base_link→laser stale, obstacle_monitor TF errors |
| topic_misconfig | base_controller relaunched with cmd_vel_topic=/cmd_vel_nav | node alive, /cmd_vel 0 subs, /cmd_vel_nav 0 pubs, param wrong |
| node_crash | obstacle_monitor exits | node missing, /scan 0 subs, /obstacle_distance gone |
| random | supervisor picks one; identity only in a ground-truth file the agent never reads | |

### Evidence model
Every tool call returns structured data plus deterministic **findings** (`E1`, `E2`, …) generated by code from the data.
The LLM's diagnosis must cite finding IDs. Code validates: IDs exist, ≥2 cited, ≥1 anomaly, the repair target is
referenced by a cited finding, action is on the allowlist. Confidence = heuristic score computed from the cited evidence
(breakdown shown in UI). Failed validation → the agent is told why and keeps investigating; if it still fails →
INCONCLUSIVE, no repair.
